Add a new user

Creates a real login for them and grants dashboard access in one step. Share the email/password with them directly — they can change it anytime via "Change password" in their dashboard after first login (there's still no forgot-password reset if they lose it). Optionally set a trial end date: access is automatically revoked once it passes, and they'll see a heads-up when a day is left.

People with access

"Revoke" blocks access immediately but keeps the account on file so you can "Restore" it later. The 🗑 button permanently deletes the access record — this can't be undone, and unlike Revoke it can't be restored. Neither one erases the underlying Firebase login itself (that needs the Firebase console: Authentication → Users), so keep passwords private regardless.
