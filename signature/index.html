Add it to Gmail

  1. Click Copy full signature above.
  2. In Gmail: ⚙ Settings → See all settings → General, scroll to Signature.
  3. + Create new, name it (e.g. Kaizen — full), click into the box and paste with ⌘V.
  4. Under Signature defaults, pick it for new emails. Optionally use the compact one for replies/forwards.
  5. Scroll to the bottom, click Save Changes, and send yourself a test email.

Tip: if the copy button is blocked, select the signature in the white box with your mouse, copy, and paste. The formatting comes with it.
